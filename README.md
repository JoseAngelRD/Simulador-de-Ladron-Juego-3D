# 🗡️ Boss Hunter 2D

**Boss Hunter 2D** es un juego de acción y plataformas en dos dimensiones centrado en épicos combates contra jefes (Boss Rush). El jugador deberá aprender los patrones de ataque de los enemigos, y demostrar sus reflejos para salir victorioso.
---

## 🎮 Características principales
* **Combates:** Cada jefe tiene mecánicas y fases distintas que requieren diferentes estrategias.
* **Movimiento fluido:** Controles precisos diseñados para una experiencia de juego ágil.
* **Pixel Art / Estética 2D:** Apartado visual cuidado y animaciones frame a frame.

---

## 🛠️ Tecnologías y Herramientas utilizadas
* **Motor de juego:** [Unity]
* **Lenguaje de Programación:** [C#]
* **Control de versiones:** Git & GitHub
